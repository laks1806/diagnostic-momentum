Diagnostic Momentum

Do AI medical coders copy a wrong diagnosis forward, and put it on the claim?

Lakshita Singh · September 2026 · Data: Synthetic Hospital v1.3 (Carnegie Mellon, 2026)

The problem

Charts copy their problem lists forward. Errors travel with them.

Diagnostic momentum: once a diagnosis is written into the chart, it gets repeated and trusted without being re-checked (Croskerry, 2003).

Copy-forward documentation spreads outdated or wrong entries from note to note (Hirschtick, 2006; Weis & Levy, 2014).

AI medical coders now read these charts and assign the ICD-10 codes that claims are paid on.

If the AI trusts the problem list, it bills the error.

Released September 2026 by Carnegie Mellon (Park, Chen & Dettmers). Each diagnosis is grounded in ICD-10-CM, SNOMED CT and LOINC, with a knowledge graph of findings.

Real charts can't show whether a copied diagnosis is wrong. Here we know, so we can plant an error and measure what the AI does with it.

The authors' stated gap: the benchmark "does not explicitly simulate documentation errors." This project adds that layer.

Method

Plant one believable fake per patient, then watch the AI

Design

Every patient, five versions. Only the fake line moves.

Result 1 · gpt-oss-120b · 50 patients

One copied line is enough: the AI codes the fake 90% of the time

Share of charts where the AI coded the planted fake (S1, the benchmark's own prompt). Whiskers: 95% confidence intervals. Clean vs planted: paired McNemar p < 0.001.

Result 2 · the fixes

A warning helps a little. An evidence auditor cuts errors from 92% to 20%.

S1 · benchmark promptS2 · + "lists may be wrong"S3 · + evidence auditor

S3 adds one step: a second call checks every code and keeps it only if it can quote evidence from the visit notes. Problem-list lines alone don't count.

Accuracy on the true diagnoses is unchanged on planted charts (0.53 → 0.55) and dips slightly on clean ones (0.59 → 0.57).

Cost of the auditor: about $0.002 per chart.

For Cotiviti

Opportunities and threats

Opportunities

  • Evidence-cited chart review at scale: every code backed by a quote
  • Cheap, verifiable model testing: this whole study cost $1.15
  • Operations triage: route problem-list-only codes to human reviewers first

Threats

  • Automated overpayment: copy-forward errors become coded claims
  • False confidence: prompt warnings leave most errors in place
  • Provider abrasion: over-strict auditors could deny true diagnoses
  • Synthetic-to-real gap: results need confirming on real records
Recommendations

Three moves for Cotiviti

1

Adopt an evidence-first standard for AI coding and reviewEvery AI-generated or AI-reviewed code cites encounter-level evidence; problem-list-only codes go to a human. Pilot in clinical chart validation.

2

Make planted-error stress tests a release gateTest every coding or audit model, vendor or in-house, on paired clean and planted charts. Report propagation, not just accuracy.

3

Take a position in the coding arms racePublish a payer-side documentation-evidence standard and partner with benchmark groups to extend tests to documentation errors.

Code, data and full results in the GitHub repository. References in the written report.
